# Tarot Daily

เว็บแอปเปิดไพ่ทำนายจากสำรับภาพ 78 ใบ เลือกเปิดไพ่ได้ 1, 2 หรือ 3 ใบ โดยไพ่จะไม่ซ้ำกันภายในรอบเดียว

## ใช้งานในเครื่อง

เปิด `index.html` ได้ทันที หรือรันเซิร์ฟเวอร์แบบง่าย ๆ:

```powershell
python -m http.server 4173
```

จากนั้นเปิด `http://localhost:4173`

## ใช้กับ Hostinger

อัปโหลดไฟล์ทั้งหมดใน repository นี้เข้าโฟลเดอร์ `public_html` โดยให้ `index.html` อยู่ที่ระดับบนสุด ไฟล์ภาพในโฟลเดอร์ `tarot-cards` ต้องอัปโหลดไปพร้อมกันด้วย

โปรเจกต์นี้เป็น static web app ไม่ต้องใช้ฐานข้อมูลหรือ backend

> ใช้เพื่อความบันเทิงและการสะท้อนความคิดเท่านั้น
